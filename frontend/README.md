# frontend

Interface do Suporte Ampère em Next.js 15 (App Router, TypeScript, Tailwind). São duas páginas: o chat em `/` (seletor de Cliente, lista de Conversas, mensagens com streaming por SSE, indicador da Ação em andamento e aviso de Aprovação Pendente) e a Tela do Atendente em `/atendente` (Aprovações Pendentes, Tickets e Memória Procedural por Cliente, protegida por token). Não há nenhuma lógica de domínio aqui: o front só chama a API e renderiza o que ela devolve. Para rodar, copie `.env.example` para `.env.local`, ajuste `NEXT_PUBLIC_API_URL` (endereço da API, padrão `http://localhost:8000`) e execute `npm install` e `npm run dev`; a página abre em `http://localhost:3000`. O `Dockerfile` gera a imagem em modo standalone e a variável `NEXT_PUBLIC_API_URL` precisa ser passada como `--build-arg` no build, porque ela é embutida no bundle.
