# grafo

O que é: o grafo do LangGraph com oito nós, na ordem em que uma mensagem os atravessa: `carregar_memoria`, `guardrail_entrada`, `roteador`, `recuperar_contexto`, `gerar_resposta`, `agente`, `guardrail_saida` e `salvar_memoria`. O estado (`estado.py`) é a Memória de Curto Prazo da Conversa, persistida pelo checkpointer do Postgres, um thread por Conversa. Cada nó tem o system prompt num arquivo próprio em `prompts/`, com nome e versão que vão como metadata do trace. Por que assim: é a única pasta que importa das outras (rag, memoria, guardrails, roteador, acoes, observabilidade), então dá para abrir `nos.py` e ler o fluxo inteiro de cima para baixo sem pular de camada; o nó `agente` é um só e se repete com `Command(goto="agente")`, de modo que a interrupção do Reembolso acontece num passo em que só Ações rodam, e a retomada com `Command(resume=...)` não chama o LLM de novo. Teoria em um parágrafo: um grafo de estado é uma máquina de estados onde cada nó lê e escreve num dicionário compartilhado e as arestas decidem o próximo nó; o checkpointer grava o estado a cada passo, o que dá pausa e retomada (human-in-the-loop), replay e testes determinísticos com modelos falsos.
