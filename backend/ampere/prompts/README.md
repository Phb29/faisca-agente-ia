# prompts

O que é: tudo o que um modelo de linguagem lê, um arquivo markdown por prompt, com `nome` e `versao` no frontmatter. Os três primeiros são dos nós do grafo que escrevem ou resumem (`gerar_resposta`, `agente`, `resumir_conversa`), os três seguintes são tarefas de bastidor do trabalhador (`resumir_ticket`, `extrair_memorias`, `self_querying`) e os três `juiz_*` são as perguntas binárias dos evals. As variáveis aparecem como `{{variavel}}` e `renderizar` exige todas, nem uma a mais nem uma a menos, porque um `{{contexto}}` que escapa para o modelo é um bug silencioso. Nome e versão vão como metadata de cada chamada, então no Langfuse dá para saber qual versão de qual prompt produziu cada resposta. Por que numa pasta só: prompt é conteúdo, não lógica, e quem apresenta ou revisa o comportamento do chatbot abre uma pasta e lê tudo o que os modelos recebem, sem caçar strings no código. A pasta não importa de nenhum outro módulo, e qualquer um pode ler dela (ver `docs/adr/0005`). Teoria em um parágrafo: tratar prompt como artefato versionado, e não como string solta, é o que permite comparar versões num eval, reverter uma mudança ruim e ler um trace sabendo exatamente o que o modelo viu.
